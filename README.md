# CarRental

Навчальний проєкт з дисципліни «Конструювання програмного
забезпечення». Варіант № 7: бронювання автомобілів у прокаті.

## Склад рішення
- CarRental.Core — логіка предметної області (бібліотека)
- CarRental.App — консольний застосунок (введення, виведення)

## Вимоги
.NET SDK 8.0 або новіший, Git.

## Складання та запуск
    dotnet build
    dotnet run --project CarRental.App

## Стандарт кодування
Правила описано у файлі CODING_STANDARD.md і закріплено
в .editorconfig. Перевірка: dotnet format --verify-no-changes
