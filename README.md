# CarRental

![CI](https://github.com/zivak0707-lang/CarRental/actions/workflows/ci.yml/badge.svg?branch=main)

Навчальний проєкт з дисципліни «Конструювання програмного
забезпечення». Варіант № 7: бронювання автомобілів у прокаті.

## Склад рішення
- CarRental.Core — логіка предметної області (бібліотека)
- CarRental.App — консольний застосунок (введення, виведення)

## Вимоги
.NET SDK 8.0 або новіший, Git.

## Складання та запуск
    dotnet build
    dotnet run --project CarRental.App

## Стандарт кодування
Правила описано у файлі CODING_STANDARD.md і закріплено
в .editorconfig. Перевірка: dotnet format --verify-no-changes

## Обробка помилок і журнал (ЛР5)
- Помилки вводу повертаються як Result: застосунок пояснює помилку й питає знову.
- Порушення правил предметної області — DomainRuleException з ідентифікатором правила.
- Журнал виводиться в консоль (Microsoft.Extensions.Logging, рівні Debug–Critical).
- Файли audit.log і reports/ створюються під час запуску й до репозиторію не потрапляють.

Класифікацію помилок наведено в docs/errors.md.

## Безперервна інтеграція (ЛР8)
Конвеєр .github/workflows/ci.yml запускається на push і pull request.
Критерії якості: форматування без змін, складання Release без попереджень,
100 % зелених тестів, покриття рядків не менше 60 %.
