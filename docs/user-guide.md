# Посібник користувача CarRental

Посібник для оператора філії прокату, який бачить застосунок уперше. Сценарії UC-01…UC-06
описано в `docs/spec.md`; тут — як ними користуватися.

## 1. Запуск

У теці репозиторію виконайте:

```
dotnet run --project src/CarRental.ConsoleApp
```

Одразу після запуску видно назву застосунку і меню:

```
CarRental — облік прокату автомобілів філії

1. Забронювати автомобіль
2. Видати автомобіль
3. Закрити оренду
4. Скасувати бронювання
5. Знайти оренди
6. Звіт «Зайнятість автопарку»
0. Вихід
Оберіть пункт:
```

Введіть номер пункту й натисніть Enter. Після кожної дії меню показується знову.
Пункт `0` завершує роботу.

Моменти часу вводяться у форматі `yyyy-MM-dd HH:mm`, дати — `yyyy-MM-dd`. Порожній ввід
у полі «Початок оренди» означає «зараз», у полі «Дата звіту» — «сьогодні».

## 2. Прохідні сценарії

Нижче — фактичний ввід (після двокрапки) і фактичний вивід застосунку.

### 2.1. Забронювати автомобіль (пункт 1)

```
Оберіть пункт: 1
Код клієнта: 5
Державний номер авто: aa8130po
Початок оренди (yyyy-MM-dd HH:mm, Enter — зараз): 2026-11-20 10:00
Кількість діб: 3
Заброньовано: договір № 1141, AA8130PO, 20.11.2026 10:00 – 23.11.2026 10:00, 900,00 грн за добу
```

Номер авто можна вводити малими літерами. Ціна доби береться з тарифу класу авто і
фіксується в договорі: пізніша зміна тарифу на цей договір не впливає.

### 2.2. Видати автомобіль (пункт 2)

```
Оберіть пункт: 2
Номер договору: 1125
Видано: договір № 1125, AA1112KX, о 14.11.2026 14:03
```

Момент видачі — поточний час комп'ютера.

### 2.3. Закрити оренду з запізненням (пункт 3)

```
Оберіть пункт: 3
Номер договору: 1106
Закрито. Діб: 10; прокат 9 000,00 грн; штраф 2 250,00 грн; до сплати 11 250,00 грн
```

Авто видано 05.11 об 11:15 з плановим поверненням 10.11 об 11:00, а повернуто 14.11 о 14:03.
Доби: 9 діб 2 год 48 хв розпочатих — 10 × 900 грн. Запізнення 4 доби 3 год, мінус пільга
60 хв — 5 розпочатих діб × 450 грн (50 % ціни доби).

### 2.4. Знайти оренди (пункт 5)

```
Оберіть пункт: 5
Стан: 1 — заброньовано, 2 — видано, 3 — закрито, 4 — скасовано
Стан (Enter — будь-який): 2
Частина імені клієнта (Enter — будь-яке):
Державний номер (Enter — будь-який):
Знайдено: 16
№ 1106 | AA5360KX | Ткаченко Дмитро          | видано       | 05.11.2026 11:00 – 10.11.2026 11:00
№ 1107 | AA7888EP | Ткаченко Іван            | видано       | 06.11.2026 09:00 – 09.11.2026 09:00
...
```

Критерії поєднуються: можна задати лише частину прізвища або лише номер авто.

### 2.5. Звіт «Зайнятість автопарку» (пункт 6)

```
Оберіть пункт: 6
Дата звіту (yyyy-MM-dd, Enter — сьогодні):
Зайнятість автопарку на 14.11.2026
Клас       | Усього | Видано | Заброньовано | Вільно | Зайнятість
Economy    |     22 |      9 |            0 |     13 |     40,9 %
Compact    |     18 |      4 |            0 |     14 |     22,2 %
Suv        |     12 |      1 |            0 |     11 |      8,3 %
Premium    |      8 |      2 |            0 |      6 |     25,0 %
Разом      |     60 |     16 |            0 |     44 |     26,7 %
```

«Заброньовано» — авто з бронюванням, період якого охоплює дату звіту; видане авто
рахується лише як видане.

## 3. Повідомлення про помилки

| Повідомлення | Що сталося | Що робити |
|---|---|---|
| `Такого пункту немає; введіть число від 0 до 6.` | у меню введено інше значення | ввести номер пункту |
| `Потрібне ціле число, наприклад 1001.` | у числове поле введено текст | повторити ввід — застосунок запитає ще раз |
| `Потрібен формат yyyy-MM-dd HH:mm, наприклад 2026-11-20 10:00.` | момент введено в іншому форматі | ввести дату й час через дефіси і пробіл |
| `Відмова: Номер автомобіля не вказано.` | поле номера авто порожнє | почати бронювання знову і ввести номер |
| `Відмова: Клієнта з кодом 500 не знайдено.` | клієнта немає в довіднику | перевірити код у картці клієнта |
| `Відмова: Автомобіля AA0000ZZ у парку немає.` | авто немає в довіднику | перевірити державний номер |
| `Відмова: Тривалість оренди — від 1 до 30 діб, а введено 45.` | тривалість поза межами | оформити кілька договорів поспіль |
| `Відмова: Початок оренди не може бути в минулому.` | початок раніше ніж 15 хв тому | ввести майбутній момент або залишити порожнім |
| `Відмова: Автомобіль AA8130PO уже заброньовано або видано на цей період.` | період перетинається з відкритим договором | обрати інше авто або інший період |
| `Відмова: Договору № 9999 не знайдено.` | номера договору немає | знайти договір пунктом 5 |
| `Відмова: Період оренди минув; потрібне нове бронювання.` | спроба видати авто після планового кінця | оформити нове бронювання |
| `Відхилено: Дію «закрити» заборонено для оренди у стані Reserved.` | дія недопустима для поточного стану | спершу видати авто; закритий чи скасований договір змінити не можна |
| `Помилка даних: Файл …/cars.json пошкоджено: …` | файл даних зіпсовано, застосунок завершується з кодом 1 | відновити теку `data/` з резервної копії |

## 4. Дані й резервна копія

Дані лежать у теці `data/` поряд із місцем запуску:

| Файл | Вміст |
|---|---|
| `cars.json` | автопарк: номер, модель, клас |
| `customers.json` | клієнти: код, ім'я, номер посвідчення |
| `tariffs.json` | ціна доби для кожного класу |
| `rentals.json` | усі договори оренди; застосунок змінює лише цей файл |

Застосунок записує `rentals.json` спершу в тимчасовий файл і лише потім підміняє ним
основний, тож перерваний запис не псує дані. Щоб зробити резервну копію, закрийте
застосунок і скопіюйте теку `data/` цілком, наприклад у Windows:

```
xcopy data data-backup-2026-11-16\ /E /I
```

Для відновлення закрийте застосунок і скопіюйте файли з резервної теки назад у `data/`.
Журнал роботи — `logs/carrental.log`; його можна видаляти, застосунок створить новий.
